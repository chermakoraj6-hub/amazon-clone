# Amazon Clone

A frontend replica of the Amazon web interface built to practice semantic HTML layout structures and advanced CSS styling techniques.

## 🚀 Features
* Semantic HTML5 layout
* Responsive navigation bar and search bar styling
* Amazon-style product grid and card layouts
* Hover effects and interactive UI elements using CSS
* Clean, organized code written in VS Code

## 🛠️ Tech Stack
* HTML5
* CSS3
